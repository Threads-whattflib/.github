# Threads-whattflib

👋 這裡放我自己在用的交易小工具，整理後開源。
背景是電機所碩士、目前做 ML／Edge AI 相關工作，習慣把東西做成能自架、能驗證的樣子。

所有工具都只用公開資料或你自己的 API key，不收集任何資料；程式全部公開，歡迎自己檢查。

## 工具

| 專案 | 做什麼 |
|---|---|
| [open-chart-desk](https://github.com/Threads-whattflib/open-chart-desk) | 自架的 TradingView 式看盤網頁：加密貨幣／台股／美股、畫線、觀察清單、價格提醒，一個 Docker 容器 |
| [quiet-farmer](https://github.com/Threads-whattflib/quiet-farmer) | MAX／BitoPro 每日自動刷統一發票：每天一筆最低手續費的 USDT/TWD 交易 |

## 使用前

- 都是個人整理的開源專案，**依現狀提供、不保證正確**；跟 TradingView、交易所、財政部都沒有關係。
- 行情資料來自公開介面，可能延遲；任何工具都不構成投資建議。
- 會下單的工具一律只開「交易」權限的 API key，**不要開提領**。
- 建議請 AI coding agent（Claude Code、Codex、Cursor…）照各 repo 的說明幫你安裝並確認。
- 歡迎 fork 魔改；issue／PR 不保證會回。
